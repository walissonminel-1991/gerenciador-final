**Project summary:**

> Gerenciador Final is a free and open-source Windows desktop application written in C# and Windows Forms (.NET 10). It aims to make routine PC maintenance easier for non-technical users, including managing application updates with WinGet, selective cleanup, built-in Windows diagnostics, network connectivity checks, power plans and system information. Operations that change the system are gated by user confirmation and elevation when required. The project does not disable antivirus protection or automatically modify firewall exceptions.
